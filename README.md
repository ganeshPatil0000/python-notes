## How I take notes
1. Open the topic's `notes.md`.
2. Tick the subtopics as I finish them.
3. Write the explanation in my own words, add a small code example.
4. Write the code in `03-practice/` and run it.
5. Add interview questions at the end.

## Run the practice code
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
python 03-practice/core-python/01_basics.py
```
